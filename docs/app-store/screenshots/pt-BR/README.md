authentic Astro results, completed-session context, capture planning, and local
media creation.

## Publication status

These files are visual candidates. The supplied Astro photographs are authentic;
the populated UI states were composed from Camerae's tracked visual evidence.
Before App Store publication, compare controls, labels, and represented behavior
with the shipping build and replace concept-only UI with device-captured UI where
