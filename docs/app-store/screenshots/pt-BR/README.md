# Camerae App Store screenshots — PT-BR

This set presents Camerae through six moments on each supported device family:
two authentic Astro results followed by four screens captured from the v9
interface running in the simulator.

## iPhone 6.9-inch

All files are 1290 × 2796 PNG images without alpha transparency.

1. `01-via-lactea-1290x2796.png` — authentic Milky Way result in the Camerae
   viewer.
2. `02-quintal-astro-1290x2796.png` — authentic backyard result and completed
   Astro session.
3. `03-inicio-camerae-1290x2796.png` — v9 home and module selection.
4. `04-novo-projeto-astro-1290x2796.png` — Astro project creation.
5. `05-configuracao-astro-1290x2796.png` — Astro session and exposure controls.
6. `06-configuracao-repeatable-1290x2796.png` — Repeatable timelapse
   configuration.

## Publication status

These files are publication candidates. The supplied Astro photographs are
authentic. Screens 3–6 were captured from build 26 of the v9 app with the tracked
UI-evidence test in PT-BR. The test supplies a deterministic simulated Main
camera because the iOS Simulator has no physical camera; production camera
detection remains unchanged.
